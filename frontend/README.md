# /app/frontend — Emergent preview stub

**This folder is NOT part of the portable project.**

It exists solely to keep the Emergent preview panel working during
development. It renders a single informational screen describing the real
project structure.

The **real mobile app** is at [`apps/mobile/`](../apps/mobile/), which is a
standard, fully portable Expo project.

If you exported this repo to GitHub, you can safely delete `/app/frontend`
and `/app/backend`.
